# bnu_cms_api

A lightweight **Python Flask** scraping microservice and REST API providing structured JSON feeds for university student portals.

## Features
- **Session Management**: Automated authentication handling captcha and cookie state.
- **Clean JSON Endpoints**: Scrapes raw portal HTML tables and returns clean, structured data for grades, attendance, and fees.
- **Cloud Deployment**: Preconfigured with `render.yaml` for deployment on cloud platforms.\n
